A CakePHP plugin providing [Latte](https://latte.nette.org/) template engine integration for CakePHP applications.

## Installation

This branch supports CakePHP 6 and PHP 8.5+. Use the main branch for CakePHP 5.

CakePHP 6 currently requires development dependencies. Set `"minimum-stability": "dev"` and `"prefer-stable": true` in your application's composer.json, then install:

```bash
composer require josbeir/cakephp-latte-view:dev-cake6
```
